Avant de démarrer les labs, vous trouverez ici les **supports de cours** (slides)
et un **pense-bête `kubectl`** avec les quelques commandes Kubernetes utilisées
pendant la formation.

> 💡 Kubernetes n'est pas le sujet de cette formation : c'est juste l'outil qui
> fait tourner la plateforme d'observabilité. Toutes les commandes nécessaires
> sont fournies dans les labs — le pense-bête est là uniquement pour vous mettre
> à l'aise.
