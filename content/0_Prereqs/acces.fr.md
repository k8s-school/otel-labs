Tout se passe dans votre navigateur, rien à installer sur votre poste.

## Le serveur de formation

* **URL** : <https://training.k8s-school.fr/>
* **Compte** : `student<N>` — le formateur vous donne votre numéro et votre mot de passe en début de session.

Vous arrivez sur un bureau distant avec un terminal et un navigateur. Votre cluster Kubernetes y est déjà créé, avec les images chargées : le premier lab n'a plus que la démo à installer.

> 💡 Chaque participant a sa propre adresse pour ouvrir les interfaces web : `student3` utilise `http://localhost3:8080/`, pas `http://localhost:8080/`. Le premier lab explique pourquoi — retenez juste que le numéro de votre compte se retrouve dans vos URLs.

## Le document d'échange

Un pad partagé, ouvert pendant toute la formation : <https://annuel.framapad.org/p/k8s-school-otel>

Il sert à tout ce qui passe mal à l'oral :

* poser une question sans interrompre, le formateur y répond entre deux labs ;
* récupérer une commande ou une URL au lieu de la recopier depuis l'écran ;
* signaler un lab qui bloque, avec le message d'erreur copié tel quel.

Pas de compte à créer, il suffit d'ouvrir le lien.
